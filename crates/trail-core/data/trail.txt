# ================================================================
#  TRAIL DATA FILE  -  this is the game's "mod file"
# ================================================================
#  Everything about the trail lives here: the landmarks, how far
#  apart they are, store prices, animals you can hunt, fish,
#  plants you can gather, sicknesses and the names the game suggests.
#
#  HOW TO HACK IT
#   - Lines starting with # are comments. The game ignores them.
#   - A word in [brackets] starts a new thing (a landmark, an animal...).
#   - Below it, write   key = value   lines.
#   - In the web version, open "Mod editor", change something,
#     press "Apply". If you make a mistake the game tells you
#     which line is wrong. On the Cardputer, rebuild the firmware.
#
#  IDEAS: make buffalo weigh 5000 pounds. Make oxen cost $1.
#  Add a landmark called "My Secret Base" at mile 400.
# ================================================================
